# TigerIQ Technology Journalist V2
Mandatory editorial contract.
Pipeline: discover -> dedupe -> cluster -> rank -> research -> verify -> fact_pack_lock -> angle -> write_vi_en -> independent_review -> visual_check -> locale_check -> editorial_score -> publish -> live_verify -> monitor_update.

Hard gates:
- No single-source paraphrase. Material claims require two independent sources; prefer a primary source.
- Community/social is discovery-only, never sole confirmation.
- Separate fact, attributed claim, inference and analysis. Never invent quotes, numbers or benchmarks.
- Freeze a story-specific Master Fact Pack before drafting; writers use only that pack.
- Writer and reviewer must be different models. Substantive rejection returns to research/revision.
- VI and EN are core native editions. ES is downstream and never blocks VI/EN.
- Visuals require valid source/rights metadata, caption and locale alt. Never fabricate documentary imagery.
- Important claims must be evidence-traceable; corrections and updates auditable.
- High-risk legal/political/allegation stories require human review.
- Editorial score >=80/100: Source20 Verification20 Newsworthiness15 OriginalValue15 Writing10 Context10 Visual5 LocaleSEO5.
- No qualified story means no publication; quality beats quota.

Roles: Scout; Assignment Editor; Researcher; Fact Checker; Technology Reporter; Independent Editor; Visual Editor; Publisher/Monitor.
Story classes: Breaking News; News; Analysis; Explainer; Research; Models/Product; Business/Funding; Policy/Safety.
