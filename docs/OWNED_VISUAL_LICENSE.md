# TigerIQ News — Owned Original Raster Cover License

Status: active for TigerIQ News Visual V2.

## Scope

Raster covers generated by the TigerIQ News publisher from the repository-owned procedural illustration code are **owned-original illustrations**. They do not incorporate third-party image bytes and do not inherit rights from the source publisher's `og:image`.

- Owner / attribution: **TigerIQ Media**
- Authoring system: **TigerIQ Newsroom procedural illustration renderer**
- Permitted use: TigerIQ Media editorial pages, OpenGraph/Twitter cards, archives and related first-party distribution.
- AI image generation: **No**. The fallback is deterministic procedural SVG artwork rendered locally to JPEG.
- Source article facts and image rights are separate: the source article remains cited for reporting; the fallback cover remains TigerIQ-owned.

## Generated cover source

The final raster file committed under `covers/<slug>.jpg` is the canonical source asset for that article. The Visual V2 record binds its SHA-256, byte count, pixel dimensions, rights class and this rights-evidence URL before publication.

This fallback is used only when a publisher image does not provide sufficient explicit license/copyright/AI-disclosure metadata. It must not convert an unverified third-party image into an approved asset.
